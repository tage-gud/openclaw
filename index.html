Understanding OpenClaw

What is OpenClaw?

OpenClaw is a free, open-source AI agent that runs locally and can take actions on your computer — not just generate responses. It's not another chatbot competing with tools like ChatGPT or Claude, but part of a new wave of AI agents that don't just respond, they actually act. They run commands, move files, send messages, and handle multi-step tasks in the background while you get on with your day. Emergent

OpenClaw functions as a local gateway that gives AI models direct access to read and write files, run scripts, and control browsers through a secure sandbox. Many describe it as "self-improving," likened to AGI, because it can autonomously write code to create new skills, implement proactive automation, and maintain long-term memory of user preferences. Background and History

OpenClaw was developed by Austrian developer Peter Steinberger and first published in November 2025 under the name Clawdbot. The software was derived from an earlier personal project called Clawd — an AI-based virtual assistant named after Anthropic's chatbot Claude. Wikipedia

The project went through three name changes in three months: Clawdbot (November 2025), Moltbot (January 2026), and finally OpenClaw (January 30, 2026) — with a lobster as its mascot, symbolizing growth and openness. It reached 100,000 GitHub stars in roughly three months, one of the fastest growth curves in GitHub history. OpenClaw

On February 14, 2026, Steinberger announced he would be joining OpenAI, and that a non-profit foundation would be established to provide future stewardship of the OpenClaw project. Wikipedia

How Does It Work?

OpenClaw is an AI-based virtual assistant serving as an agentic interface for autonomous workflows. Bots run locally and are designed to integrate with an external large language model such as Claude, DeepSeek, or one of OpenAI's GPT models. Functionality is accessed via a chatbot within a messaging service such as Signal, Telegram, Discord, or WhatsApp. Configuration data and interaction history are stored locally, enabling persistent and adaptive behavior across sessions. OpenClaw's capabilities come from a plugin system called Skills. Each skill is a directory containing a SKILL.md file with metadata and instructions the LLM uses to understand what the skill does and when to call it. Emergent

Supported AI models include: Claude (Anthropic), GPT-4 (OpenAI), Gemini (Google), and local models via Ollama.

Supported messaging channels: WhatsApp, Telegram, Slack, Discord, Google Chat, Signal, iMessage, IRC, Microsoft Teams, Matrix, Feishu, LINE, Mattermost, Nextcloud Talk, Nostr, Synology Chat, Twitch, Zalo, WeChat, QQ, and WebChat. GitHub

There is ongoing work to enable agents to perform tasks across local and remote systems, using a blend of local persistence and external LLM services.

What Can It Do?

Users have documented OpenClaw performing real-world tasks including automatically browsing the web, summarizing PDFs, scheduling calendar entries, conducting agentic shopping, and sending and deleting emails on a user's behalf. A key feature is its persistent memory, which allows the agent to recall past interactions over weeks and adapt to user habits to carry out hyper-personalized functions. CNBC

  • Automated web browsing and data extraction
  • Document summarization (PDFs, HTML, etc.)
  • Calendar scheduling and reminders
  • Agentic shopping and task orchestration
  • Emails and messages management on behalf of the user
  • Long-term memory for personalized behavior

Cost

OpenClaw is MIT licensed and free. You pay for LLM API usage ($10–150/month depending on how much you use it). Light users may spend around $10–20/month, while heavy usage can exceed $100/month depending on configuration. BuildMVPFast

Installation

The easiest way to get started is via the terminal using openclaw onboard, which guides you step by step through setting up the gateway, workspace, channels, and skills. It also installs the Gateway daemon (launchd/systemd user service) so it stays running in the background.

bash
npm install -g openclaw@latest
# or:
pnpm add -g openclaw@latest

openclaw onboard --install-daemon
